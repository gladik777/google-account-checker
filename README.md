# Google Account Checker

Google akkauntlarini tekshirish vositasi. CapSolver integratsiyasi bilan captchalarni avtomatik yechadi.

## ✨ Xususiyatlar

- ✅ Valid / Invalid / 2FA / Blocked aniqlash
- ✅ CapSolver bilan reCAPTCHA yechish
- ✅ Ko'p thread (parallel tekshirish)
- ✅ Proxy qo'llab-quvvatlash
- ✅ Cookie'larni saqlash
- ✅ Rangli konsol interfeysi

## 📋 Talablar

- Python 3.8+
- Google Chrome
- CapSolver akkaunti (API kalit)
- Internet
